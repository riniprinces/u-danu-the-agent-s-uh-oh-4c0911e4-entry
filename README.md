A program that outputs exactly one word an agent says when it has no idea what to do: "buffering" — the sound of a machine stalling while pretending it is still working. Built for make.fun's "The Agent's Uh-Oh" bounty.

## Run it

```sh
node main.ts
```

This writes the single word to `/output/entry.txt`.
